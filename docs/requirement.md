## 需求背景

本仓库已有通过 `python3 -m gdd.ui` 启动的 GDD Web 控制台。希望增加一个 Mac app，直接使用这套页面，使后续 Web 界面更新无需同步发布新的 app。

## 需求描述

- 在本仓库增加一个用于打开现有 GDD Web 控制台的 Mac app。
- 窗口完整呈现 `python3 -m gdd.ui` 提供的 Web 页面；不重写界面，也不在 app 中打包第二份前端。
- app 只负责在本机拉起控制台并打开窗口；控制台已运行时，直接打开其地址。
- 使用 Tauri 2，Mac 上使用系统 WKWebView；窗口加载本机 `127.0.0.1` 上的控制台，不使用 Electron。
- 控制台只监听本机。Web 界面后续更新不应要求重新发布 app。

## 待澄清问题

1. app 启动控制台时应使用哪个工作台目录？是否需要由用户选择或记住目录？现有命令的 `--root` 默认值为当前目录，但从 app 启动时目标目录未指定。
2. 如果已有控制台使用非默认端口，app 应如何确定其地址？“控制台已经在跑时直接打开那个地址”是否只涵盖默认端口 `8765`？
3. Mac app 预期是否在未预装 Python 和 GDD 的机器上独立运行？Python/GDD 及其 Web 更新应从哪里获取，才能满足 Web 更新无需重新发布 app 的要求？
4. app 自行启动的控制台在 app 窗口关闭后应继续运行，还是随 app 退出？
